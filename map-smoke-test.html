RO’Lyfe Auction Capital Machine — Map Smoke Test

Checklist for the live application after the map bridge is integrated. This page is documentation only; it does not load the production app.

  1. Confirm the map renders tiles and displays OpenStreetMap attribution.
  2. Click Global: reference city pins appear and the status explicitly says live weather/news is not connected.
  3. Click States: state-capital pins appear and the status says boundaries are not loaded.
  4. Enter a county and state, then click Counties: a location pin is shown if lookup succeeds; no polygon is implied.
  5. Enter a complete property address, click Map Current Property, and verify the returned pin against an independent map.
  6. Click Street: the map zooms closer to the address if a result is found.
  7. Click Reset: returns to Global view without a blank map.
  8. Test with the internet disconnected: status reports that the map/location service is unavailable instead of silently claiming success.
  9. Check mobile layout, button states, console errors, and that no duplicate Leaflet map initialization occurs after repeated mode changes.
  10. Confirm that no screen labels the reference pins as live weather, live auction, verified parcel, or official boundaries.
